json-typestack

Paste several JSON samples of the same shape. A field missing from any one of them is optional; a field that is null in one of them is nullable. Those are different things, and all five outputs below keep them apart.

 

    TypeScript

    email?: string means the key can be absent. email: string | null means it is always there and can hold null.

    
  
    
  
    
    
    Zod
    
    
    Plain ESM, so it runs without a build step. Objects are non-strict, matching
      additionalProperties: true in the JSON Schema.
    
    
    
  
    
  
    
    
    JSON Schema (draft 2020-12)
    
    
    Optional keys are left out of required. Nullable keys get
      "null" added to their type.
    
    
    
  
    
  
    
    
    Postgres
    
    
    A row cannot express an absent column, so optional and nullable both become a
      nullable column and the comment says which one it was.
    
    
    
  
    
  
    
    
    Example fixtures
    
    
    minimal carries only the required keys, full carries
      every key, nulls is null wherever null is allowed. All three validate against
      the schemas above.
    
    
    
  
    

    


    Same generator as the command line tool:
  npx json-typestack --name User samples.json.
  Everything runs in this page; nothing is uploaded.
